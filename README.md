# Adaptive AI Skill Gap Analyzer

## Overview

Adaptive AI Skill Gap Analyzer is an AI-powered career guidance platform that helps students, freshers, and job seekers identify skill gaps, measure career readiness, and receive personalized learning recommendations for their target job roles.

The platform analyzes a user's existing skills, compares them against industry requirements, and generates customized roadmaps, readiness insights, and learning recommendations to help users become job-ready efficiently.

---

## Problem Statement

Many learners struggle to understand:

* Which skills are required for their target career.
* What skills they currently lack.
* How job-ready they are.
* What learning path they should follow.
* Which skills have the highest impact on employability.

Most existing career guidance systems provide generic recommendations and fail to deliver personalized, explainable, and adaptive guidance.

This project addresses these challenges by providing intelligent skill analysis, personalized recommendations, career readiness prediction, and Explainable AI (XAI)-based insights.

---

## Key Features

### Skill Gap Analysis

* Compares user skills with industry-required skills.
* Detects missing competencies for selected career paths.

### Personalized Recommendations

* Suggests skills to learn based on individual profiles.
* Prioritizes learning based on career impact.

### Explainable AI (XAI)

* Explains why a skill is recommended.
* Improves transparency and user understanding.

### Career Readiness Assessment

* Calculates readiness scores.
* Provides visual progress tracking.

### Learning Roadmaps

* Generates structured beginner-to-advanced learning paths.
* Guides users toward career goals step-by-step.

### Role-Based Quizzes

* Evaluates knowledge through domain-specific assessments.
* Tracks learning progress continuously.

### Progress Tracking

* Monitors completed skills and roadmap progress.
* Updates recommendations dynamically.

### Future Readiness Prediction

* Estimates future career readiness based on learning progress.

## Installation

### Clone Repository

```bash
git clone https://github.com/poonamnikhade/adaptive-ai-skill-gap-analyzer.git
```

### Navigate to Project Folder

```bash
cd adaptive-ai-skill-gap-analyzer
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

### Open Browser

```text
http://localhost:5000
```
